# DailyOS

**Telegram Mini App, который превращает хаос дня в понятный следующий шаг.**

DailyOS принимает обычное сообщение, голосовое или скриншот в Telegram, выделяет из него реальные задачи и помогает собрать спокойный маршрут дня. Пользователь всегда видит, что будет добавлено, и подтверждает задачи сам.

## Что умеет

- Разбирать текст, голосовые и скриншоты из Telegram в задачи с датой, временем и длительностью.
- Показывать маршрут дня без перегруженного списка дел.
- Давать AI-разбор «выгрузки мыслей»: идеи, покупки и дедлайны можно отправить одним сообщением.
- Напоминать в Telegram о воде, зарядке, сне и задачах за 15 минут до начала.
- Сохранять рецепты из продуктов, проводить короткую зарядку и подводить итоги дня.
- Работать в светлой и тёмной теме; данные хранятся локально, а в Telegram синхронизируются, когда CloudStorage доступен.

## Сценарий демо на 40 секунд

1. Отправить боту: «До пятницы отправить презентацию, купить продукты, записаться к врачу».
2. Нажать «Разобрать в DailyOS» и подтвердить найденные задачи.
3. На главном экране открыть «Маршрут дня».
4. Открыть «Входящие»: видно, что задачи пришли из Telegram.
5. В профиле включить напоминание и показать, что приложение не только планирует, но и возвращает к плану в течение дня.

## Технологии

- Python, `aiohttp`, `aiogram` — Telegram-бот и API.
- Telegram Web Apps — авторизация, интерфейс и CloudStorage.
- Groq API — структурированный AI-разбор текста, голоса и изображений.
- TomTom API — поиск мест рядом по запросу пользователя.
- Один адаптивный HTML-интерфейс без тяжёлого клиентского фреймворка.

## Запуск локально

```powershell
pip install -r requirements.txt
$env:BOT_TOKEN = "токен_бота"
$env:APP_URL = "https://ваш-публичный-домен"
python bot.py
```

Необязательные переменные окружения:

- `GROQ_API_KEY` — AI-разбор, голосовые и фото.
- `TOMTOM_API_KEY` — поиск мест рядом.
- `GROQ_MODEL`, `GROQ_AUDIO_MODEL`, `GROQ_VISION_MODEL` — выбор моделей Groq.

Для работы Telegram webhook нужен публичный HTTPS-домен. Конфигурация для Render находится в [render.yaml](render.yaml).

## Надёжность и приватность

- Каждый API-запрос проверяет подпись Telegram `initData`.
- AI- и геопоисковые запросы ограничены по размеру и частоте.
- Переданные боту заметки для открытия Mini App живут в памяти не более 15 минут и выдаются только тому же Telegram-пользователю.
- Координаты для поиска мест используются только в момент запроса и не сохраняются.
